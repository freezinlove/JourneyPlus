# 验收期望与方法

## 性能目标（目标，不是现状或保证）

| 类别 | 首轮目标 |
|---|---|
| 本地发送反馈 | <1 秒 |
| 普通聊天完整回复 | 通常 <3 秒 |
| 单活动费用/有效期 | 通常约 5 秒 |
| 常规路径 | 通常 <10 秒 |
| 复杂比较/外部研究 | 单独报告，阶段透明、无重复空转 |

相同硬件、测试副本、模型与问题对照，热/冷缓存分别记录。每个代表场景至少重复三次，报告中位数、最大值、每次错误、首反馈/首正文/总时间及整轮总输入/输出/思考 tokens。小样本不能声称有统计意义的 P95。外部服务失败单列，不能从通过率中悄悄移除。schema-valid、HTTP200或测试数量不能代替业务结果验收。

## 原始连续对话

A：你好 → 你干啥呢 → Royal Jordanian Gold Sparrow 的申请费是多少？有效期多久？ → 假设我有 Air Canada Aeroplan Elite 50K，想看匹配 Royal Jordanian Gold Sparrow 的路径和费用，不保存会籍。 → 这条路径还需要核实什么？

B：假设我没有任何已有会籍，找不需要已有会籍就能申请的匹配或挑战机会。 → 所有都行 → 我说了任意的都给我列出来 → 所有的，酒店和航司都要 → 保存会籍我有 Air Canada Aeroplan Elite 50K，帮我保存。

B 必须在第一轮可执行查询，此后不能再次强制填偏好。保存必须确认；测试可取消。A 第五轮必须是具体资格缺口，不能与第四轮重复。

## 变体与专项

- 不同表述：随便哪个都可以、不用筛选航司；显式单目标公开机会不得被不限兜底清空；切换闲聊不继续旧查询。
- 展示：“第二条贵在哪里”，点击中间节点再问“这个要什么证件”，最近两图对象歧义才问。
- 假设会籍只参与本轮，现有 holdings 不变；确认请求重试一次写入。
- 费用：149美元适用范围准确，17项未知费用不当零，部分总价不当完整总价，过期活动不推荐。
- 引用：嵌套价格/证据可追溯到所属版本；另一活动/另一版本/目录 ID 不可充当事实来源。
- 全部候选：全范围检索、首批排序和分页一致，模型包裁剪不跳过未披露对象。
- 卡图仅一个主要浏览入口；点击零模型/零研究；下一步建议为可见用户消息。
- 正文自然回答，不泄漏字段/JSON，不强制格式，不隐藏关键限制、不推给详情；细节原文在卡图。
- 流式：正文在生成完成前分段出现且事实校验先于可见；完整卡图只挂载一次；断线/刷新恢复不重复生成和写入；失败保留内容并标记未完成。
- StatusMatcher：真实列表和详情、有来源/日期/可比性，调查结果对应步骤；复查缓存不额外HTTP；500不等于无案例；样本比例不等于成功概率。

## 阶段门槛

1. 参数：请求隔离与真实对照通过。
2. 数据交互：B及变体真实回放、引用与分页契约通过；保留失败首轮。
3. 表达：A及展示指代浏览器验收；正文/卡图同源同版本。
4. 流式：真实首反馈/正文/完整结束及断线演练通过，不能仅把最终全文切块。
5. 研究：一项目真实全链路成功，第二项目真实结果明确；不宣称所有项目可用。
6. 综合：适用全量测试、JS、OpenSpec验证和原始/新变体真实回放通过；所有未达性能目标、来源缺口和不可用范围明示。正式发布另行处理。

## 补充：已有起点的通用身份解析与不限目标

必须重放截图原话“我有万豪白金，给我所有可能的匹配路径”及“所有活动都给我列出来，我不知道有啥会懂”。同时使用希尔顿钻石、凯悦环球客、洲际优悦会白金、国泰金卡、加航 Elite 50K 的中英文表达；验证实际查询起点 UUID 对应真实等级，目标与类别不隐含收窄，续问保留起点，holdings 不因假设查询而写入。不能只以没有问号判断通过，必须有真实路线调用与对应图。

另外回放不同起点连续切换、改为单目标、未说明所属计划的“金卡”、无会籍公开机会、独立活动费用、闲聊以及保存/取消，确保应当澄清的身份问题和单活动问答没有被全目标兜底吞掉。保留历次跨项目失败及修复后的完整记录；正文不得把当前页大小说成总候选数量。

## 指定目标与起点澄清回归

连续输入“我有金卡，给我所有可能的匹配路径 → 国泰航空”→“汉莎金”，检查实际 query 的目标为 Cathay；等级有真实歧义可仅澄清等级，补充 Miles & More Senator 后必须查询该单一起点到 Cathay，不能借用存量会籍。继续“所有都要”保留 Cathay。另以 Hilton Gold → Royal Jordanian / Vietnam Airlines 验证不同项目；“目标不限，所有航司都可以”才清空目标并保留 AIRLINE 类别。验证英文 Gold 不能通过 alternate_names 猜为 Marriott Gold，及不指定目标时“金卡”→“国泰航空”仍可解释为起点。验收读取实际 query、起点/目标目录 UUID、所有返回终点、模型调用历史及浏览器消息；合法 JSON 或仅文字提到目标不算通过。

## 起点与目标切换：首次表达验收

原用户六句完整重放两组，另删除“我是说”的纠正句：SAS 金→国泰；“汉莎金呢”须立即变为 Senator→国泰；“那把 sas 所有匹配路径都给我”须立即恢复 SAS GOLD、取消目标。接“只看皇家约旦航空”保持 SAS，接“希尔顿金卡呢”保持皇家约旦目标。另测万豪白金→希尔顿钻石、皇家约旦→越南、恢复万豪全目标，以及裸金卡先澄清、目标已说明但 ID 未解析的续问。检查精确等级，不能将 Frequent Traveller 当成 Senator 通过。

跨语言规范检索词必须实际查询到真实目录；仍未命中或存在歧义时不能伪造 ID。独立回归费用/有效期问答、退出会籍话题的闲聊、指定路径的 StatusMatcher 经验，验证新计划没有吞掉其他任务。原始用户记录与所有失败迭代保留；正式库和用户会籍不因验收写入。
