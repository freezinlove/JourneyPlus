### 代码结果

- `knowledge/refresh.py`：官方 HOME/FAQ/Terms 完整快照、已识别的单活动文章，统一进入来源准备、短引用提取、校验、原子发布和简报派生。相同来源重复运行跳过提取；失败保留已发布版本；单篇文章的新来源版本按已绑定来源和项目延续活动身份。一文多活动没有分段依据时 DEFERRED，不用全文硬套每个活动。
- 统一提取只允许模型填写 facts/options，活动/版本/来源清单由服务端绑定。使用短引用并在嵌套类型验证前还原真实 ID；JSON Schema 显式表达 known_state 和价格/来源范围约束，最多一次格式修复。对齐已有申请方式 logical_key，不继承旧版本已消失的事实。
