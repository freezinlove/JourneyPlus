# 新旧读取影子验收

本报告为隔离数据库验收，不执行正式消费者切换。原始机器结果放在 `.secrets/knowledge-validation/20260906/shadow-read-*.json`，由 `scripts/compare_knowledge_reads.py` 在 PostgreSQL REPEATABLE READ、READ ONLY 事务生成。

## 比较边界

- 原隔离库保留两条原用户会籍：旧图 35 条边，新结果 22 条路线、13 个共享步骤。边和多步路线不是同一计数单位，不能用相减判断召回变化。
- 回填验收副本另有恢复演练创建的一条测试会籍，旧图因此是 39 条边；不能与原库 35 条边直接比较。所有当前旧图边现可沿事实版本 FK 找到已发布的新活动。
- 旧 LoyaltyLobby 快照不进入正式新库；副本中的旧文章发布仅验证文章链路。正式切换前必须排除该验证数据，不能复制整个测试库。

## 已核对的差异分类

| 差异 | 原因与判断 |
|---|---|
| 旧官方卡链接初次全为 NOT_FOUND | 实际链接是 fact set ID，原兼容实现只识别 event ID；这是实现缺陷，已补 FK 解析并在真实浏览器打开 Air Astana 旧链接验证 |
| 原隔离库有 9 条边关联尚未发布活动 | Kenya／Vietnam 关联未完成；不能把缺失当作旧图错误。两项已在副本回填，全部原图边的活动身份现可解析 |
| Vietnam 同一来源旧边展示 USD129／159／149／199 | 旧价格标签汇集了不同申请办法。新版本分通用航空、Alaska、酒店、信用卡；关联不足的价格保持 UNKNOWN，不能任选最低价 |
| Kenya 短费用标题与完整目标等级无法证明对应 | 暂不自动把 Gold 解释成 Gold Elite Plus。9 项费用未知、信用卡明确 USD99；保留原证据供详情核对，不声称价格信息完整 |
| Vietnam 费用仍有 8 项未知 | 限定收费证据尚未通过关联校验；信用卡明确 USD199。此次完成的是安全回填和缺口报告，不是所有报价已恢复 |
| Air Astana 一般申请费与可选付费升级 | 已知一般申请费 USD49；USD199 升级资格保留在相关材料，不能把高等级升级费加入以低等级为终点的所有路径，也不能宣称无升级选项 |
| Royal Jordanian 不同来源／目标收费 | 航空 Gold Sparrow USD149 与酒店 Silver Jay USD49 分别绑定；相同品牌不意味着全部来源可按最低价取得任意等级 |
| Club Avolta 明确免费与 Radisson 无已知费用 | 前者有免费证据，后者保持未知；没有价格不能推定免费 |
| Vietnam 名称词序和括号使后续路径断开 | 同一项目被旧目录存为两份，这是身份衔接缺陷。仅加入已审查的确切拼写等价与官方表头等级别名，不做全库模糊合并；历史 ID 不删除 |
| 新图有更多同目标路线 | 保留多种到达办法和来源取得历史；不能依旧图仅保留最短线的结果删掉备选。完整候选在服务器，默认只披露首批 |
| 新结果带 UNKNOWN／PARTIAL 或资格待核实 | 未知挑战、证件、日期、来源取得条件及费用不再由单步通过抵消；MATCH 只表示用户本次筛选条件满足，不代表审批资格全部证实 |
