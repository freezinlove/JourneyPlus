## Context

当前正式模型已满足存储需求。路径工具将地区方案乘进每次遍历，重复步骤编号还依赖完整前缀；等待仅保留命中步骤，导致相同查询表现不一致。

## Goals / Non-Goals

统一程序最短会籍搜索、最高等级展示、免费开关和紧凑结果。不更改数据库模型、原始事实或 AIWorkflow，不增加 LLM 调用或业务资格推断。

## Decisions

- 多源广度优先搜索，每个等级只确定一个最短到达前驱；先过滤免费要求，身份节点避免环。结果按目标计划选最高已知等级，显式等级不替换；必要中转保留。
- 明确等级顺序放在读取侧简单配置，未知顺序不伪造最高等级，保留并标明未知。绝不对未知名称强行按字母选最高。
- 会籍连接只携带二元费用和活动版本入口；目标等级的任一明确必付费报价归为付费，可选附加费用不算，缺失费用按免费。地区价格资料不随路线复制。
- 结果前缀合并，步骤按身份关系去重；探索状态在函数返回后释放。所有消费者使用同一紧凑结果，不另建知识表。
- 保留现有会话 artifact 和版本机制，仅保存最终连接。旧查询版本明确过期；旧有效等待的金额/地区条件不静默丢弃，返回需要更新的状态。

## Risks / Trade-offs

- 最高目标等级可能比低等级需要更多跳 → 先算每个等级最短路径，再选择最高可达等级。
- 低等级可能拥有独有后继 → 只隐藏独立终点，不删除必要搜索节点。
- 忽略地区意味着费用标记不是地区报价承诺 → 精确地区/金额由 activity.read 按需读取。
- 旧测试断言精确费用已不符合需求 → 改为验证默认不带费用细节且活动详情原样保留。

## Migration Plan

无数据库迁移。重启服务接入新工具 schema；旧临时结果要求重新查询，业务事实与用户记录保留。用正常网页真实 Qwen、正式库完成验收并比对六张核心表。
