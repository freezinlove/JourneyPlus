# 查询循环与矩阵修复

## 实现

- 重组提示词：缺失用户意图先澄清，事实缺失才调查；删除必须交付图表的倾向，匹配图不能用完整活动表替代。
- routes.evaluate 保留内部身份解析与路径计算。缺来源在准备阶段返回，search_performed=false、total=null，不进入图搜索。
- 名称解析支持完全由同一项目已登记别名组成的中英文名称；不同项目组合及未知尾词保持未解析。
- 本轮相同参数及快照的成功读取（含空结果）复用；刷新绕过，写入使缓存失效。不跨用户轮次缓存。
- 缺条件结果持续作为当前轮事实提醒，后续读取资料不会自动消除；有效查询可清除。没有固定工具链或按次数强迫交图。
- 同一次上下文准备的共享知识库可用性检查只执行一次。
- 增加 tools.timing，记录工具批次（含结果保存和容量检查）耗时、调用及复用数。历史未记录阶段不能事后精确拆分。
- 对话和新闻共用矩阵组件：项目为行、目标等级为列、条件展开。不直接打印映射剩余字段。

## 验证

- 35 项 Python 针对性测试通过，覆盖运行时、结果解释、别名、缺来源不搜索、缓存、进展提醒。
- 3 项浏览器测试通过：矩阵合并行列/条件展开，历史与实时展示回归。
- TypeScript/Vite 构建、compileall、diff --check 通过。
- 使用正式配置模型和真实知识库；创建验收会话，不修改账号当前会话或保存的会籍。
- 迭代中真实模型曾出现额外目录查询、预设追问方向、冗余建议；不是每次测试都通过。对应修复后再次验收，原始测试会话保留在数据库中。
- 明确免费路径请求：routes.evaluate → display.present，约15.2秒；无 activity.read。
- 最终无结果请求与两次模糊请求由 scripts/accept_agent_query_flow.py 验收，断言调用形式、无替代表格和追问方向。自然语言仍需人工审阅，不能把有限样本当作模型永远不偏离的保证。
