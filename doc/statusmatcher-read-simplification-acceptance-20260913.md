# StatusMatcher 读取简化验收（2026-09-13）

本文记录第一阶段验收。后续已将报告解析统一到 `web.read`，取消单独 `research.parse` 与展示阶段解析；当前行为见 [报告入口统一验收](statusmatcher-unified-read-acceptance-20260913.md)。

## 实施范围

本次只处理报告丢失结尾、重复结果判断、页面噪声和经验卡片正文。公司目录查找、自动展开第一家公司、工具调度及模型选择逻辑保持现有实现。未修改 AIWorkflow、业务数据库结构或业务数据；实测产生的会话、网页快照和展示结果按原有工作区机制保存。

- 报告解析不再使用 600 字符摘要或英文短语结果分类器。网站标签和完整报告正文分别保留，缺字段不生成另一份“未知”结论。
- `research.parse` 输入仅剩 `page_refs`。取消会籍对比、匹配方式参数及数据库目录查询，输出不再携带空会籍 ID、固定说明和可比性结论。
- 原始 HTML 不变。模型读取视图清除 StatusMatcher 的广告、投稿表单、登录提示、侧栏以及报告旁枚举全部等级的色块。报告中的证明材料、身份验证说明继续保留，清洗不使用业务关键词。
- 短报告完整返回；较长报告的首次工具结果保留最多 6000 字节正文，明确标记尚未展示完，并提供 `full_text_ref`，通过已有 `workspace.read` 分页找回全文。完整文本保存在 REPORT 对象中，不再只有不可恢复的前 600 字符。
- 卡片只做带省略号的短预览；详情显示完整已获取正文、网站标签、提交日期和原报告链接。模型直接展示 PAGE 时也复用相同解析器，不要求额外一次模型或解析工具调用。
- 原有下载上限、超时、临时快照期限继续有效。源响应本身未完整获取时保留明确提示；“完整正文”不代表越过这些既有读取边界。

## 真实页面和第三方模型

通过正式工具入口读取肯尼亚航空公司页及报告 137243、136433，并逐篇对比网页 `.instructions` 正文：两篇提取正文与网页规范化空白后的全文一致。

- 公司页保留 34/58、59% 的网站汇总、两个报告方向、申请入口和两种方向的历史翻页链接；去掉投稿表单、用户管理和页脚。
- 国泰钻石到 Asante Rewards 白金：完整保留身份验证过程及最后“约 24 小时完成匹配”的结尾，网站标签 MATCH，提交日期 2026-08-24。
- 雅高白金到 Asante Rewards 白金：保留 USD 299、身份检查、约半小时获批以及不需住宿记录的正文，网站标签 MATCH，提交日期 2026-08-06。

使用当前第三方模型 **qwen3.8-flash**，显式缓存开启，正式数据库和真实网络。给模型普通自然语言调查请求，由模型自行选择工具，没有预先脚本化工具调用。调查及后续卡片展示均 COMPLETED。

调查中模型曾拼错一个卡片引用；工具拒绝后，模型自行使用正确引用恢复。模型对正文的自然语言概括仍可能有细微扩大，例如将“不能再次点击完成验证”表述成“链接只能点一次”，或补充报告未证实的审批影响因素；不把运行完成或关键事实正确当成全文零误述保证。本次没有为这些模型表述增加新判断规则或提示词约束。

浏览器验收打开了模型实际生成的卡片，分别覆盖 REPORT 对象和直接 PAGE 展示两条入口；均看到完整成功结尾、标签、日期和来源链接，无页面脚本错误。浏览器仅用于本地界面验收，未将 StatusMatcher 获取方式替换为 Playwright。
