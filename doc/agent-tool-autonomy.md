# Agent 工具参数减负与验收

2026-09-12。按用户确认的方案实施。模型负责理解用户意图、选择工具和业务参数；程序自动记录执行背景。数据库结构和 AIWorkflow 未改，未创建 Git 提交。

## 改动

- `routes.evaluate` 删除 `constraint_changes` 和 `source_message_refs`。`query_ref + patch` 继续继承未修改条件；程序计算新旧值差异并关联执行轮次，不再强制逐字段引文或理由，也不把轮次关联说成字段语义已验证。
- `holdings.write`、`waiting.manage` 删除 `authorization` 和 `operation_key`。程序从当前真实用户轮次取得执行背景，保存到现有回执 JSON；`semantic_authorization_verified=false` 明确它不是语义授权证明。对象引用、版本冲突、事务和真实回执保留。
- 防重复逻辑集中在 `services/operation_context.py`：同次调用按稳定调用标识恢复；新调用仅在同轮、规范化参数相同、记录的执行后状态仍与当前对象一致时复用效果，并为新调用保存 NOOP 回执。状态变化、新轮次以及删除后重新创建不错误复用旧结果。
- `workspace.note` 删除模型填写的 `source_message_refs`，程序自动关联当前轮次。笔记仍是模型内容，版本检查保留。
- `research.parse` 删除没有参与解析的 `context` 参数。同步更新工具说明、指令和目标架构。
- Harness 的业务无关执行循环、渐进式披露、模型选择图卡和自然语言交付方式保留。自动记录不增加模型调用。
