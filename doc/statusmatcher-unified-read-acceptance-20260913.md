# StatusMatcher 报告入口统一验收（2026-09-13）

## 结果与范围

模型读取 StatusMatcher 报告只使用 `web.read`。程序在读取时提取网站字段、保存报告；移除单独的 `research.parse` 工具及其输入输出契约。没有增加模型调用，搜索选择和是否展示仍由模型决定。

四项能力全部保留：

| 能力 | 统一后的实现 |
| --- | --- |
| 经验卡片及完整详情 | `display.present` 使用 `report_ref` 读取已保存的正文 |
| 模型读取结构化字段 | `web.read.report` 返回来源会籍、目标会籍、网站标签、日期及正文完整性；正文只在 `text` 返回一次 |
| 独立报告对象 | `report_ref` 可通过 `workspace.read` 分页回读，按原有工作区 24 小时有效期保留 |
| 路线图和比较卡片附件 | 两种展示的 `research_refs` 均可使用同一报告引用 |

PAGE 保留原始 HTML，并指向一次读取生成的 REPORT。网页与报告在同一事务中保存，失败不会留下半份快照。后续分页复用相同对象；刷新生成新快照，不修改旧报告。展示层接收到 PAGE 引用时仅转到已经保存的 REPORT，不再解析网页。

公司页面和其他网站保持原来的读取方式，不自动生成报告。报告布局无法识别时保留可读正文、返回 PARTIAL 和解析错误，不伪造结构化报告。原有下载大小、超时与工作区有效期继续适用。

未修改 AIWorkflow、数据库模型、业务活动或会籍数据，也未修改 Harness 核心调度。真实验收只新增正常 Agent 会话、网页与展示等工作区资料。

## 验证

专项回归 **97 passed**。覆盖公司清洗、报告解析、正式原数据模型上的工具装配、分页全文恢复、刷新隔离、保存失败回滚、没有标签时不推断结果、布局异常，以及路线图和比较卡片使用 REPORT/PAGE 引用挂载同一报告。存在原有 Starlette/httpx 弃用提示，无测试失败；未宣称执行全项目全部测试。

真实调用当前配置的 **qwen3.8-flash**，显式缓存开启，使用正式数据库和真实网络。给模型自然语言调查肯尼亚航空两篇申请经验的任务，未预设工具调用。运行 COMPLETED，模型自行调用目录查找、StatusMatcher 搜索、两次网页读取及展示工具；所有工具结果 OK，没有额外解析调用。

逐篇对照实际下载网页的 `.instructions` 原文，规范化空白后与模型收到的 `text`、独立 REPORT 正文均完全一致：

- 报告 136433：195 字符，Accor Live Limitless Platinum → Asante Rewards Platinum，网站 MATCH，2026-08-06，完整保留 USD 299、身份检查、约半小时获批及无需住宿记录。

浏览器打开模型实际生成的两张卡片，核验完整结尾、日期、标签、原报告链接，未发生页面脚本错误。路线图和比较卡片附件通过自动化测试验证，本次没有宣称第三方模型逐一演示这两种附件。

模型回答正确区分国泰报告未写费用、雅高报告 USD 299，以及个人经验不能保证当前申请结果。自然语言概括仍可能扩大原话，例如将不能稍后重新点击完成验证的链接称作“一次性链接”；本次没有增加新的提示词硬约束，也不把运行完成视为模型零误述保证。
