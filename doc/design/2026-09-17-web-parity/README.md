# Web 原型还原验收 · 2026-09-17

## 基准与范围

- 视觉基准：`../2026-09-16/preview.html` 最终生效的 Web 样式与 SVG。
- 字段基准：`src/journeyplus/product/static/knowledge_ui.js`、`brief_view.js`、`route_step.js` 与实际 FastAPI 返回。
- 本次仅修改 React Web。原型、Android、FastAPI、AIWorkflow、Harness 和真实数据库均未修改。
- 产品占满浏览器视口；原型外部评审工具条、展示边框和设备外框不属于产品页面。

## 还原内容

导航位置与原始 SVG、圆形返回、所有页面核心列的宽度与留白、字体字号字重、深浅色变量、新闻列表的三列排版、会籍行与主题切换、输入框单行/多行尺寸、渐变边界、节点表面和连接线、弹窗宽度与按钮样式均按原型最终参数落实。

新对话确认、编辑取消、节点弹窗到指定版本简报、返回、Enter 发送和 Shift+Enter 换行保留真实接口行为。匹配关系仍只使用 Agent 选择的服务端路径。程序名称与等级由目录精确匹配；目录无该历史名称时保留完整原标签，避免猜测拆分。

## 字段差异的处理

- 新闻：保留原前端活动名称、摘要、历史/结束状态和北京时间更新日期。没有将演示的项目标签、示例日期或虚构记录写入产品。
- 详情：保留关系、申请链接、完整映射表、按申请方式/目标等级组织的价格表、来源、条件、可用性和冲突说明；当前资料与指定版本继续分开读取。
- 无已生成简报时展示活动已有事实，标题明确为活动资料；不伪造简报。
- 有效期未设置不解释为永久有效；真实账号名继续展示。
- 对话示例中的免责声明属于设计样本，不给真实助手回复追加此文案。

## 验证

`clients/web/e2e/visual-parity.spec.ts` 直接打开原型文件，和 React 同尺寸对照。对照移除了外部评审框；新闻的示例标签没有对应产品字段，因此在测试参考页移除，不改变产品原型源文件。

- 桌面 800、1100、1440px，各验证浅色/深色；390px 验证窄屏 Web。
- 对照检查的导航、标题、气泡、节点、输入框、新闻行、会籍行等边界误差不超过 1px；对关键元素额外核对字体、字重、行高、色彩、边线、圆角。
- 验证长输入高度、详情字段/条件展开、指定版本跳转时弹窗关闭、新对话确认与关闭。
- 9 项 Playwright 测试通过（包含隔离 FastAPI 端到端流程）；2 项图数据布局测试通过；TypeScript / Vite 构建通过。
- 截图和测试为 Chrome 环境；不是对所有浏览器和任意真实内容的全像素一致性声明。额外真实字段、长文本、分支数量变化会自然改变内容高度。
