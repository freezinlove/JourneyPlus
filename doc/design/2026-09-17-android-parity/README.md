# Android 与当前 Web / HTML 对齐

## 基准

- 视觉、字段和状态：`clients/web/src` 当前实现。
- 手机布局：`doc/design/2026-09-16/preview.html` 的 Android 模式。
- 实现：Kotlin + Jetpack Compose，真实 FastAPI / Agent API；不嵌入 WebView。

## 本次实现

- Web 相同的圆圈菱形品牌图标、导航 SVG 路径、颜色变量、背景角落渐变。
- 顶部左侧我的会籍，中间对话/新闻图标胶囊；新对话仅在对话页显示。简报详情和会籍页只保留返回按钮。
- 空对话居中引导与输入框；消息出现后输入框固定底部。多行输入、原生键盘发送、停止回答、自适应用户气泡。
- 处理状态、逐字展示；匹配结果在前置文字展示完成后显示。切换页面不会丢失已展示进度，滚出屏幕的文本不会阻塞后续图表。
- 新闻列表、简报、会籍页使用共同的颜色、字号和间距。简报关系节点、申请入口、默认折叠的匹配矩阵/价格表和来源链接。
- 移动匹配图带边框，固定横滑提示，源节点卡片，目标节点可点击；图内竖滑交给页面滚动。
- 会籍名单同列显示项目/等级，浅色/深色胶囊切换。
- 220ms 页面入场、200ms 主题切换、1.4s 处理状态脉冲。Compose 遵守系统动画时长设置。

## 验证

模拟器：Pixel 6，Android 14 / API 34，1080×2400，420dpi。

构建通过；设备自动化 6 项通过，0 失败、0 跳过；`git diff --check` 通过。截图入口为同目录 `index.html`。

自动化用例位于 `clients/android/app/src/androidTest/java/com/journeyplus/app/ParityTest.kt`：

1. 居中启动输入框和原生多行编辑。
2. 表格默认折叠、展开及重新折叠。
3. 处理状态和停止按钮，空助手消息不重复生成品牌头。
4. 未知费用不视为免费。
5. 图内横滑不移动提示、竖滑仍滚动页面。
6. 前置文字未展示完成时不提前展示程序化结果。

自动化数据仅存在于测试代码；实际页面截图来自本机服务里的账号及活动数据。没有重新执行新闻提取、改写活动事实或创建 Git 提交。

## 对照范围

HTML 截图用于布局比较；Web 手机宽度截图用于视觉比较。Android 保留原生状态栏、系统返回和键盘。Android 与 macOS 的系统字体不同，字形和断行并非逐像素相同；不能把构建通过当作“像素级完全一致”的证明。

调试 APK：`clients/android/app/build/outputs/apk/debug/app-debug.apk`。模拟器服务地址默认为 `http://10.0.2.2:8000`；实体手机需在登录页填写可以访问的服务地址。

## 关系卡片适配补充
