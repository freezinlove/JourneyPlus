# 第三版：雾光

[交互预览](./mist-preview.html) · [第一版](./preview.html) · [第二版](./liquid-preview.html)

## 本版取舍

遵循最新要求：保留第一版界面，仅借鉴第二版的背景。第二版已提交为 `dfbc508`。

- 保留第一版的字体、字号、圆角、按钮、侧栏、输入框、路径节点、简报排版和 Android 导航。
- 背景融合暖灰、雾蓝、淡紫灰和灰绿，以大面积柔和渐变呈现失焦感。
- 浅色以瓷白为基底；深色以第一版的深炭灰为基底，避免背景抢走信息层级。
- 输入框本体仍是第一版的实色表面，仅周围区域透出背景。
- 简报长文保留稳定阅读底色，费用、版本和映射表不直接覆盖在彩色光场上。
- 不引入第二版的玻璃按钮、悬浮胶囊导航、发光描边、光学球或背景动画。

## 实现与范围

`mist-preview.html` 从第一版概念稿复制，仅更新设计稿标识、对比链接并加载 `mist.css`。业务示例、交互脚本及基础组件样式保持第一版内容。

`mist.css` 只覆盖应用背景、输入区域外围背景和阅读区域底色。无需新增依赖，无需运行实时模糊。

本版仍是虚构数据的独立交互原型，支持 Web / Android、浅色 / 深色；未接入业务接口，未修改生产前端或核心逻辑。第三版暂留工作区供比较，不包含在第二版提交中。
