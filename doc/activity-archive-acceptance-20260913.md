# 活动结束与软归档验收（2026-09-13）

已实施库内软归档。保留现有 AIWorkflow 数据模型、事实、简报、映射、价格、来源链接及原文快照；本次没有数据库迁移，没有清空或修改正式业务数据，没有创建 Git 提交。

## 实施范围

- `lifecycle/visibility.py` 统一读取时的有效状态；官方图、文章图、目录、匹配、简报、Agent 及缓存版本采用相同规则。过期隐藏不依赖后台先运行。
- 截止时刻本身有效，超过后结束；日期按现有北京时间规则解释。官方没有截止日期不新增失效天数。文章的 180 天资料窗口与官方结束分开标记；维护与读取使用同一归档判断。
- 官方首页关闭仍只由 HOME 判断。FAQ/Terms 只参与内容变更；网络失败不会被当作活动结束。后台重复归档不改变第一次归档时间。
- 同站点重新开放创建独立事件和首版事实、简报。新事件有独立生产任务和提取缓存标识；恢复为以前出现过的首页也不会命中上一活动的完成任务。只有 FAQ/Terms 或提示版本变化，不会重开已经结束的项目。提取期间发生结束，停止向原活动发布。
- Agent 适配层重新检查活动详情、原文、历史、资料分页、路线成员、展示及间接资料引用；缓存回送和上下文投影也检查。Harness 只接入通用视图回调，未重写模型—工具循环、预算、模型接口或工具选择逻辑。
- 公共知识页使用人工历史读取口；旧链接仍可打开。简报默认排除结束记录，勾选“显示已结束和已归档的简报”后可查看，标记“已结束”“资料已过期”或“已归档”。标题、摘要和简报更新时间不因结束而改写。

## 视图边界与生效方式

含结束活动的旧复合快照整体失效，需要重新查询生成当前快照。涉及结束活动的历史轮次中，模型文字和工具观察在 Agent 视图中替换为不可用说明；原始会话及资料继续留档。受影响会话的模型笔记暂不送入上下文，避免旧结论通过笔记回来；持久化会籍没有删除或修改。

过滤范围为系统提供给 Agent 的数据库知识及其派生记录，不删除用户自己输入的文字，不限制网页研究工具访问外部网页，也不限制人工历史页面。已发送过的旧回答保留为历史记录。

已更新目标架构文档。现有后台和 API 进程需要重新加载代码后使用新逻辑；本次没有重启用户正在运行的正式服务。测试浏览器及专用测试 HTTP 服务在验收后关闭。

原始日志、只读核验结果、浏览器截图及测试数据库位于 Git 忽略目录 `.local/agent-audits/activity-lifecycle/`；此目录不纳入文档或 Git 追踪。最终专项日志为 `acceptance.log`，全量日志为 `accepted-suite.log`。
