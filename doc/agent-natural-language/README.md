# 自然语言对话与模型自主图卡展示

2026-09-12。按用户确认的需求实施：用户交流全部使用自然语言；结构化内容由图、卡片和比较表承载；模型自主决定是否展示、何时展示及展示对象。

## 实现

- 删除 `BusinessCompletion`、最终回答 DTO、CompletionPort 及其组装注入。
- 删除最终回答 Schema 注入、原生协议的回答 JSON 模式、逐字段值拼接、重复交付清单检查和回答校验失败重试。工具协议本身的参数验证、流式调用完整性检查及 JSON actions 模型适配仍保留。
- 模型正文直接产生 `text_delta`，调用工具前后的自然语言同样保存、回放；取消或中断保留已收到的文字。旧记录中被拒绝的内部草稿仍隐藏，已显示的历史回答保持可读。
- 指令明确自然语言回答，详细结构化展示走现有 `display.present`。没有增加自然语言解析器、自动出图规则或额外模型调用。
- 前端继续分别处理文字、展示及实际操作事件；移除废弃交付失败提示，接口错误使用自然语言提示，供应商错误码保留在运行事件中而不拼入用户提示。更新页面资源版本。
- 目标架构文档同步新职责；历史信封式验收要求不再是当前实现依据。

没有修改数据库结构、AIWorkflow、工具参数 Schema、展示服务、查询语义、渐进式披露、写入授权、幂等、冲突或实际操作回执。工具定义和原有资源上限保持原值。

`COMPLETED` 表示运行正常结束，不证明每项业务要求均已满足。模型根据实际结果说明失败或未完成事项；工具与展示系统保留真实执行/渲染结果，不再把模型填写的交付清单当作语义正确性的证明。
