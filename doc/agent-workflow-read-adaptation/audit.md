# 实际读取链路与内容审计

结论：审计发现初版适配“工具返回成功”之外的真实问题，并在读取与结果转换层修复。三个工具和机会详情读取接口已通过实库核对；存量简报的事实错误与完整 Harness 运行存储依赖仍需区分，不能据此声称整个 Agent 或全部生成内容均已正确。

## 发现与处理

| 问题 | 复现/影响 | 处理 |
| --- | --- | --- |
| 有条件的映射被隐藏 | United MileagePlus Premier 1K → Flying Blue 的两个 Platinum 地区方案在服务层存在，但工具只分页 MATCH，返回 EMPTY | 当前模型的 MATCH/UNKNOWN 均可分页，UNKNOWN 明确标注待核对；不会伪装为已证明满足资格，明确冲突仍不作为匹配项展示 |
| 地区参数没有用于价格判断 | 明确居住地为希腊、预算 EUR 250，仍把全部地区价格标为未知并漏掉 Gold 候选 | 仅解析完整、明确的国家列表，复用既有国家别名；返回希腊对应 EUR 199，排除其他明确国家列表。复杂描述、排除句和未知地名不猜测 |
| 价格索引错位 | 过滤出 Gold 后从零编号，使 Gold 的金额带着原列表 Silver 的 price-0 引用 | 保留原价格数组索引；逐项将引用反查原始金额、币种和说明 |
| 路线与详情的映射引用不一致 | 路线使用生产贡献 ID，详情使用 mapping-N，不能直接定位同一结构化片段 | 分开保留 claim_ref 与 mapping_ref，确定性定位原 FactSet 数组项；实测 inspect → activity.read → 对应 mapping section |
| 版本及简报选择不严谨 | 同一调用的两个版本可互相覆盖；同 FactSet 新增未选中简报可能覆盖 current_brief_id；历史详情接口可能混入当前简报；旧文章一律标为 current | 冲突版本返回 STALE_REFERENCE；优先使用已选定且属于相应 FactSet 的简报，历史版本只选本版本简报；旧文章版本正确标注非当前 |
| 链接页面只有外壳可用 | `/opportunities/{id}` 返回 200，但 `/v1/match-opportunities/{id}` 返回 503 | 会籍列表读取只选原模型已有字段，保留原路径逻辑；机会详情 HTML 和 JSON 实测均为 200，简报与该版本记录一致 |
| 渐进式披露缺少完整简报入口 | 概览只有摘要，完整简报未单独列入可展开目录 | 增加 brief_section_ref，显式展开时读取完整简报，不将全文加入概览 |
| 混合挑战表述可能误判 | “Silver 无挑战、Gold 需挑战”因为出现 No challenge 而被一律标为无挑战 | 正反表述共存或字段有冲突时保持 UNKNOWN，文字要求保留 |

没有改 Harness 内核、模型决策循环、AIWorkflow 生产逻辑、数据库模型、迁移或正式业务数据。除了工具和共享读取适配，修复涉及 `product/holdings.py` 的只读选列及 `product/opportunities.py` 的简报版本选择，用于打通工具实际返回的机会页链接；没有扩展会籍写入逻辑。

## 正式库对照结果

通过 PostgreSQL READ ONLY 事务读取正式库，工具工作区工件放在临时隔离 SQLite，未启动应用 lifespan 维护任务。可重复运行脚本见 [audit_read_chain.py](audit_read_chain.py)，完整结果见 [audit-verification.json](audit-verification.json)。

- FactSet 的 14 个字段（含元数据）逐字段一致。
- 104 条原始匹配记录、4 条地区申请路线、12 条价格与原始 JSON 一致。
- 97 条可计算映射完整进入读取图；按地区与不可用等级展开后，302 个组合全部存在，无遗漏或新增。
- 302 次费用引用反查通过，金额、币种、说明及原价格索引一致；不可用报价不会作为可支付费用。
- 3 份归档的 normalized_body 通过 4 个工具分片重新拼接，全文完全一致。raw_body 未改动；这里校验的是对 Agent 披露的归档正文，不是重新联网抓取。
- 完整简报片段与指定简报记录逐项一致，默认概览约 1.55 KB。
- Air Canada Aeroplan Elite 50K 默认查询返回 4 个地区候选；加上希腊及 EUR 250 预算，返回对应 EUR 199 候选。
- United MileagePlus Premier 1K 的两个条件方案正常返回 UNKNOWN，可展开查看，不再返回空结果。
- 分页无遗漏或重复，路线展开能定位到对应映射片段，机会详情页面与数据接口均为 200。
- 正式库全部表的数据指纹在审计前后相同，也与切库时留档相同；记录到的正式库 INSERT/UPDATE/DELETE/DDL 数量为 0。模型调用数为 0。

相关回归测试：195 通过，10 项因没有指定可写的隔离 PostgreSQL 测试库而跳过，1 项排除。排除项是此前已确认的输入结构预算测试原有失败（HEAD 与工作区同为 8046，阈值 8000），没有通过修改 Harness 预算掩盖它。

## 仍需明确的边界

“读取与原记录一致”不等于“原记录的每句话都正确”。现有简报包含：

> 申请费用因地区及等级不同，范围从EUR 89（希腊/Silver）到USD 399（阿根廷等/Platinum）。

而同一 FactSet 中，Argentina/Chile 及 Brazil 的 Platinum 均为 UNAVAILABLE。另一个地区组才有 USD 399 的 Platinum 价格；简报自身后面的限制说明也与该费用句冲突。此错误来自已有简报内容，读取层忠实保留，本次未改写业务数据或重新调用模型。

本次验证没有部署完整 Agent：正式库中当前 Harness 所需的会话、执行、工件运行存储仍未补齐，其他记忆写入、等待任务及独立网页入口也不能一概判定可用。原买分数据的专门消费适配未纳入这三个会籍/匹配工具的审计范围；实库目前仅有 Flying Blue 业务样本，普通文章等分支用隔离测试库覆盖，不能声称其他真实来源已实测。

代码、测试和审计文件均未提交 Git。
