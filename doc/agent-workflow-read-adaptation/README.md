# Agent 工具读取适配记录

2026-09-12，按用户确认的范围完成三个工具及其必要接线的适配，并完成后续实库内容审计。后续审计发现并修复了初次验证未覆盖的漏读和引用问题，详见 [audit.md](audit.md)。正式数据模型仍为原 AIWorkflow 的 `status_events`、`fact_sets`、`briefs` 和文章相关表；此次没有数据库迁移、生产数据写入或模型调用。

`compose_business` 默认接入 `WorkflowKnowledgePort`。该入口只读当前业务库，复用已有官方与文章匹配关系、名称目录、事实详情及路径结果汇总函数。会籍引用由现有名称键确定性生成，只用于工具引用，不新增目录表、不做双写，也不自动回退读取弃用的统一知识表。显式注入其他读取端口仅用于保留既有独立测试和组装能力。

- `catalog.lookup`：读取现有匹配目录，保留名称、别名、明确引用和分页。它仍是会籍名称工具；活动搜索由 `activity.read` 负责。
- `activity.read`：读取当前活动/文章分析及指定 FactSet/分析版本，保留简报、申请与来源链接、补充文章信息。摘要不携带整篇原文；结构化详情可继续展开单项匹配关系。来源目录提供 `document:UUID:chunk` 引用，仅显式请求时读取归档原文的对应片段。
- `routes.evaluate`：接受现有显式身份或已保存会籍输入，读取原匹配关系，返回原工具契约要求的候选、步骤和版本引用。继续支持查询快照、分页、inspect/compare、多步路径及现有费用/挑战过滤。
- 展示接线：活动卡片读取同一端口，路径结果携带原机会页链接，避免在工具返回后再次直接查询弃用的活动表。展示工具本身的排序、选择及保存机制未改。

原模型的文字资格与地区条件保持可读，不增加必填字段或证据约束。明确的国家列表可按现有国家别名匹配居住地；其他文字地区条件及个人资格仍保持未知。有条件及其他 UNKNOWN 候选明确标注后供模型展开，不再被隐去为空结果。各地区申请路线分别呈现，费用只匹配对应目标等级；不跨地区取最低价、不把不可用等级的金额当成可支付费用。无起始会籍时，本轮适配不会把原模型中缺少结构化表达的公共/无卡申请规则猜成确定路径，覆盖信息明确标注 `SOURCE_IDENTITY_REQUIRED`。

Harness 核心目录、模型接口、决策循环、调用预算、完成规则、AIWorkflow、原匹配图生产逻辑、数据模型及迁移文件均未改。现有工具输入结构保持不变；只修正了读取说明。旧统一模型的测试通过显式读取端口继续运行，新增用例则使用归档的原模型建独立测试库，确保工具不依赖统一模型表。

验证结果：

- Harness、Agent 和路径评估相关回归：195 通过，10 跳过，1 排除。跳过项需要显式配置隔离的 PostgreSQL 测试库，没有对正式库运行有写入行为的测试。
- 排除的 `test_tools_schema_budget` 已单独执行并失败：输入结构估算为 8046，阈值为 8000。用 `git show HEAD:src/journeyplus/agent/tools/contracts.py` 加载改动前定义，结果同为 8046，确认是原有问题。此次没有修改输入结构或 Harness 预算。
- 新增 16 项原模型测试覆盖目录、检索、结构化展开、原文分片、版本隔离、分页、来源归属、不可用价格、地区费用、多步路径和原有会籍读取。
- 正式 PostgreSQL 上通过真实工具注册器执行 Flying Blue 目录、概览、详情、来源目录、指定原文片段、路径查询/展开以及结果展示，均成功。工具工作区记录写入临时隔离 SQLite，正式库始终只读。
- 初次验证的概览为 1323 字节、结构化详情为 7630 字节。审计补充版本状态和完整简报的按需引用后，概览为 1553 字节；原文仍另行按需展开。示例查询 Air Canada Aeroplan Elite 50K → Flying Blue 返回 4 个地区申请路线候选。
- 正式库 31 张表的业务数据指纹与数据库切换时留档一致，验证前后也一致。初次验证摘要见 `verification.json`，后续逐字段、逐映射和完整正文校验见 `audit-verification.json`，其中不含原文正文、密码或 API 密钥。

本轮完成的是工具消费层，不代表整个正式环境的 Agent 已完成部署适配。正式库仍缺少当前 Harness 使用的会话、工具执行、工件等运行存储结构；记忆写入、等待任务和其余产品网页/API 的原有模型依赖未纳入本轮改造。后续审计仅修复了工具所链接机会详情接口的原会籍读取字段及简报版本选择。此次没有为这些依赖加表、改库或调整其业务逻辑，完整会话运行和其余网页展示需后续单独核对。机会详情 HTML 与 JSON 数据接口已经实测返回 200；没有宣称完成浏览器视觉或真实模型完整会话测试。

所有代码、测试和记录保留在工作区，未创建 Git 提交。
