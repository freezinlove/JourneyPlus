# 架构读取缺口修复与验收（2026-09-13）

对照 `target-system-architecture.md`，修复本轮审计发现的读取、展示、配置和异常处理问题，并落实用户确认的规则：**费用信息缺失按免费；地区只作说明，不作为硬筛选。**

## 修复与逐项验收

| 问题 | 实施结果 | 验收结果 |
| --- | --- | --- |
| 过期会籍参与匹配 | 共用会籍有效日期规则；匹配图排除过期起点，保留会籍管理记录 | 临时原模型：昨天过期的会籍在匹配图、简报关系、Agent 和 explore 中均不参与；今天到期及未填有效期仍参与 |
| 免费判断不统一 | 简报、知识详情、匹配图费用文字及 Agent 路径共用费用读取规则 | 通过真实工具注册器检查缺失、空串、明确免费、已知金额、收费但金额未公布、待公布、免费基础＋可选收费、付费基础＋可选收费；缺失费用可通过免费筛选，已知付费不会误报免费 |
| 地区硬筛选 | 删除不匹配地区就排除路径的逻辑；地区仍用于说明价格适用范围 | 正式 Flying Blue 同一起点，不填地区、填 Greece、填 United States 均保留 4 个地区方案；临时双地区样例保留两条路径，USD 49 与 USD 199 分属各自方案，没有混用 |
| 历史日期、简报状态和分页错误 | 页面读取 created_at；接口按实际事实版本返回简报是否存在和下一页版本号；正文按需加载 | 真实浏览器：正式库 6 版无 Invalid Date，当前简报正确显示已存在；临时 13 版按 10＋3 翻页无重复遗漏，12 个已有简报链接各自绑定版本，1 个缺失简报正确说明；最早版本打开第 1 版摘要 |
| 映射条件漏显示及条件价格说明不完整 | 展示当前模型字符串条件、费用补充说明和条件收费标记；单条路径不继承整个活动的混合费用标签 | 真实浏览器：正式 Flying Blue 映射列表内部能看到 conditions 文字；临时样例显示条件说明、可选升级费及不作为必付金额的标记；JS 验证单路径费用标签不串范围 |
| 等待检查在空目录时异常 | 返回可重试的 KNOWLEDGE_NOT_READY，保持用户任务、条件及版本不变 | 临时数据库使用真实查询及等待服务：连续空目录检查不报异常、不误报无匹配、不改任务；知识恢复后同一任务进入 RESULT_PENDING，全程 0 模型调用 |
| 初始化覆盖上下文预算 | 初始化保留并同步 context_tokens | 真实生命周期＋本地模型适配器：12345 与 100000 配置初始化后均保持；正式配置只读探针中 12345 不再回退到 100000 |
| 独立知识服务简报 URL 404 | 共用 /knowledge 的活动＋版本＋brief 链接 | 组合服务、独立知识服务均返回 200；实际浏览器直接打开正式活动链接显示简报；历史链接保持对应版本 |
| 旧模型切换开关残留 | 正常配置与 CLI/API 移除 legacy/unified/rollback 模型切换；保留独立用户写入维护标志 | 旧环境变量设置成三种旧值均不改变当前页面和读取接口；维护时知识读取和路径查询仍可用，会籍写入口返回维护状态；旧 Agent 写入口仍返回 410 |

## 验证范围

- 全量 Python 回归：**828 passed、11 skipped**。其后费用边界与相关读取端的最终回归：**63 passed**，包含新增的“基础收费＋可选升级费”案例。
- JavaScript 图和路径回归：**7 passed**。
- 实际浏览器：本机 Chrome，正式数据库只读知识服务＋独立临时原模型知识服务；控制台无页面错误。
- 正式数据库访问设置 PostgreSQL `default_transaction_read_only=on`。迁移头仍为 `0019_original_agent_runtime`；39 张表的记录数量、来源开关、当前事实版本及简报指针与修复前基线完全一致。
- 正式数据仍为 1 个官方活动、6 版事实、6 条简报、3 份原文文档。没有清库、迁移、重新生产或修改用户业务记录。
- 本次没有重新调用第三方模型。验收覆盖实际程序工具、服务、页面与生命周期；不把本次测试表述成第三方模型全对话验收。

## 改动边界

没有修改数据库表结构、AIWorkflow 的提取或生产阶段、模型调用次数以及 Harness 的通用执行流程。变化集中在共享读取规则、工具返回、知识页面、生命周期配置及旧切换入口；Agent 提示和参数说明同步了用户确认的费用、地区语义。

目标架构和 README 已同步当前规则与运行入口。既有历史迁移、备份和历史审计材料保留，不作为当前切换机制使用。
