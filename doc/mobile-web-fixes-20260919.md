# 手机与 Web 交互修复（2026-09-19）

## 改动范围

- Android 导航图标使用按压缩放与弹簧回弹，移除圆形选中背景和默认 ripple；对话/新闻使用一个滑动选中块。Web 同步采用移动滑块与图标反馈。
- 两端发送时立即清空输入框、显示临时用户消息，服务端接受后用真实消息替换；明确失败时恢复草稿。服务端已经接受但随后读取失败，不再把已发送内容恢复为待发送内容。
- 工具调用前的文字仅作过程展示：最终回复开始或本轮结束后隐藏，保留挂在同一消息上的图形和操作结果。保留服务端原始消息，不修改模型上下文。
- Android 增加新对话确认框、新闻更新时间，缩短输入提示，压缩 Markdown 空行；简报费用与更新时间改为上下排列。
- Android 补回 presentation.answer 的显示，保证 display.present 完成回答时文字不会丢失。
- 匹配询问在有有效路径时，通过系统提示词默认选择 display.present；没有增加强制工具调用或模型完成拦截。

## KM Rewards 费用

服务器保存的官网 FAQ 表头本身同时出现 `KM Rewards Rewards Tier` 与 `KM Rewards Tier`。原文映射形成两种等级前缀，价格等级则为 Traveller / Explorer / Pioneer。

在同一项目、已有映射提供依据的范围内规范重复项目后缀，使两种表头对应同一等级，保留原始证据。另将明确收取申请费、已有结构化金额的条件申请，与可选升级费用区分；未知或冲突仍保持未知。

使用服务器当前 FactSet 的只读副本验证：三个等级价格全部识别为付费，简报 label 为“付费”。不重跑 workflow，不改数据库。旧的已生成图形是历史快照，需要重新查询才能获得新费用结果。
