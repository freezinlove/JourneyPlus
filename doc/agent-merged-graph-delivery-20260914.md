# 合并匹配图与最终展示交付验收（2026-09-14）

## 范围

本次修改 Agent 展示工具、通用运行循环的可选结束机制、路径摘要与匹配图前端。不改变数据库结构、AIWorkflow 提取链路或持久化会籍。代码未提交；真实请求、完整工具结果和对话记录保存在 Git 忽略的 `.local/agent-audits/merged-delivery/`，不放入文档目录。

## 行为

- 普通查询可由两次模型调用完成：查询；读取结果并交付自然语言答复及图卡。`display.present.complete=true` 是模型明确选择最终交付，默认 false。只有整批都是成功的最终展示才结束；额外查询、写入、错误、部分结果和主动继续都保留模型后续行动。取消仍返回取消状态。
- 模型可以在同一响应输出正文，或使用可选 `answer` 交付普通自然语言。网页在图卡上方显示这段话；它随展示存档，刷新仍可恢复。不要求最终 JSON 回复。
- 展示结束前照常保存工具调用、结果与展示记录。检查点记录交付已完成，恢复时无需补一次模型调用。
- 模型不再传比较列。程序固定生成费用和步骤两列；历史调用夹带 `columns` 时忽略此布局参数。错误对象引用、空对象和越权引用仍拒绝。
- 查询仍保留最高目标等级和最短路径；多个起点的同长度路径相同时，比较整条路径的免费/付费，免费优先。仅免费查询先排除收费边，可以找到更长的免费路径。地区和具体金额不参与搜索。
- Agent 的组合查询摘要使用“所选会籍组合”，不再用被保留的单个起点作为组合查询的标题。实际路径的来源身份留在不可变记录和 `inspect` 中；这避免把“只留下某来源的一条路径”误解成“另一个来源不能匹配”。
- 主图合并全部所选起点，合并重复连接，保留必要中间节点，路径详情默认折叠。跨查询选择的图对象再次按最高等级、最短路径和免费优先合并，保持真实路径引用，不拼造新路线。未知等级顺序仍不猜测。
- 节点详情明确显示实际来源会籍。假设/显式身份图标为“本次起点”，不把假设身份声称为持有。
- 对比表和图复用费用显示函数，`paid=true` 显示“付费”，`paid=false` 显示“免费”，无需金额字段。此前六个目标的核对结果为 Club Avolta 免费，其余五个付费。

## 验证方法与边界

使用正式服务 `127.0.0.1:8013`、正式数据库和原有 Qwen3.8-Flash，native tool calling、显式缓存开启、thinking 关闭，上下文和输入预算仍为 500000。没有预先安排模型工具调用，也没有替换模型答复。通过正常 HTTP 对话和真实网页发起请求，检查每次工具参数、保存的完整工具结果、展示对象和运行事件，未只看最终答复。

覆盖：组合查询、只看免费、取消免费限制后的对比表；真实浏览器绘图、刷新恢复、点击节点查看真实起点。自动化边界另覆盖展示成功、失败、部分结果、混合调用、多张展示、主动继续、取消、恢复、下轮工具消息配对、多根免费平局、整个路径费用、循环/重复前缀、最高等级及必要低等级中转、重复展示引用。

最终模型调用数以实际日志为准，不承诺所有请求固定两轮。模型自主追加资料读取时仍可超过两轮；已消除的是单纯为了读取成功展示回执再说一句话的调用。
