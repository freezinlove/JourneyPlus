# 统一活动知识与会籍 Agent 基线

2026-09-06 修订。本文承接已确认的整体重构设计，优先于旧版“在匹配树上增加 Agent”的实现描述。产品范围仍是会籍匹配，采用单 Agent，不扩展为通用旅行规划或多 Agent 系统。

这是已实现功能、隔离验证与发布状态的基线，**不表示正式切换完成**。实施状态以 [OpenSpec 任务](../openspec/changes/rebuild-membership-knowledge-and-agent/tasks.md)及[验证记录](../openspec/changes/rebuild-membership-knowledge-and-agent/implementation-progress.md)为准。

## 用户交互

用户可以任意自然语言输入：闲聊、活动细节、假设起点、无目标探索、路线比较或申请经验。闲聊不读业务库；活动问答不先收集全部目标，也不要求保存会籍。用户提出的临时会籍可直接用于计算，保存或修改长期会籍仍须明确确认。

返回由文本、活动卡、路线图、比较、证据及确认组成，按问题选择。图保留同一等级的不同取得路径；精选推荐最多一首选两备选，完整探索不受三条上限约束。未给目标允许探索，也可仅询问一个必要问题。

卡片／节点整体点击进入同一详情，必要时在面板内展示多个申请方式；价格和边不另设跳转。末尾下一步建议是带明确对象范围的新自然语言消息，与点击浏览分开。浏览详情／分页不调用模型，不触发经验调查。

## 数据模型与三个消费者

来源、已核实活动、展示派生数据分层，简报、关系探索和 Agent 读取同一已发布版本。

| 层 | 主要对象 | 职责 |
|---|---|---|
| 来源 | SourceItem、DocumentVersion、DocumentSection、EvidenceReference | 复用采集身份，保留原文版本与完整相关章节，精确定位证据 |
| 目录 | MembershipProgram、MembershipTier、Alias | 规范项目和等级；不凭名称或联盟身份猜等价关系 |
| 活动事实 | Activity、不可变 KnowledgeVersion、ApplicationOptionVersion、Mapping、Price | 按一次申请办法关联来源、目标、费用、条件和期限，原子切换 current 指针 |
| 派生视图 | 当前活动卡、CURRENT/UPDATE 简报、路线评估结果 | 从同一版本生成；旧回答保留旧版本，纠错不冒充官方活动更新 |
| 用户业务 | StatusHolding、AgentWaitGoal | 已确认会籍与独立等待条件，明确写入、幂等提交 |
| 临时工作区 | Interaction、Message、Turn、暂存调查 | 对话、焦点、引用、查询快照和待确认状态，到期清理 |

未知不是免费、无挑战或满足资格；来源名单未在库中核实，不等于官方未公布。费用按方案、目标、收费角色及适用范围绑定，同币种的确定可累计项才相加，不隐式换汇。互斥、附加、条件费用及冲突分别显示。

经两次提取修复仍无法验证的收费可保留 UNKNOWN 占位及来源证据，阻止其被计入确定总价；这仅适用于其他事实和映射全部通过校验的草稿。结构、范围或来源证据错误仍不发布。处理诊断不被包装成官方规则。

## 渐进式读取

模型只使用两个领域入口：`query_activity_materials` 定位目录、活动事实、FAQ/Terms、变化及证据；`query_membership_routes` 做 EXPLORE、COMPARE、INSPECT。另有受许可门控制的 `research_statusmatcher`。模型决定读取顺序，程序执行过滤、条件评估、去重、分页和引用验证。

服务器完整对象、模型决策包、页面展示包分开。概览保留判断所需的费用、限制、未知与覆盖；重复限制和期限按引用共享，详细条件计算输入及原文按需展开。不能把前几条或预算截断当作全部候选，也不能凭未披露引用取数。

当前默认模型包上限 21,000 字节、工具 token 目标 7,000；实际 Provider usage 用于校准，目录、候选、证据、历史和 Schema 占用分别观察。浏览器完整分页不受模型输入预算裁剪。

同源三组查询各三次的四格式实验中，新渐进 JSON 的事实提取均通过；首批输入中位约5,828 token，全页累计约17,029，完整精简候选约9,381。渐进包降低首次披露量，遍历全部数据未必更省或更快；这不是所有聊天任务的效果保证。原失败实验保留，详见实施记录。

## 单 Agent 运行时与记忆

沿用现有 AIProvider，使用 ANSWER／ASK／READ／PROPOSE 判别动作。每 HTTP 回合最多三次模型调用，包含最多一次格式修复；有界总时限。模型与联网发生在数据库事务之外，短事务处理工作区 revision、幂等及确认写入。

明确要求路线评估时，活动卡不能替代计算。若最后一次模型说明格式失败，但路径数据已经通过校验，程序直接展示结果并保留诊断，不追加第四次调用。有效的零结果查询同样正常生成回答和覆盖说明，不误报预算失败；明确查公开入口不要求先填写可选目标或联盟偏好。没有可用结果的失败保留用户输入和已读资料，允许恢复。

工作区从创建起固定24小时，不因消息或点击续期；待确认动作最多15分钟且不超过工作区剩余寿命。长期用户记忆仅为确认会籍。等待任务独立于工作区，条件改变需确认；每日无命中零模型／零通知，首次成功展示后默认停止，GET 读取不消费通知。

## StatusMatcher

默认关闭，需要服务器许可与用户明确经验请求。可直接调查已定位活动步骤，不必先推荐完整路线。结果按方向、等级、时间、期次、来源取得方式判可比性；未知结果不进入已知结果计数，不声称真实审批成功率，不把各步样本合并或概率连乘。

读取公司列表及选中报告详情，整次共享请求／页面／字节／截止时间预算，逐跳校验域名。最小结构化报告和观察仅临时存工作区，原始 HTML 不进长期知识库；经验与官方规则冲突时回查官方，不覆盖官方事实。

固定页面、受控HTTP、真实数据库和页面联动已验证；**真实 StatusMatcher 网站网络链路与当前页面布局仍待许可后验收**。关闭、未请求、失败、样本不足必须区别说明。

## 来源接入与回填

旧 LoyaltyLobby 文章不回填正式新库，可用于隔离验证。新文章以 published_at ≥ 2026-09-06 00:00 Asia/Shanghai 为界，发布时间缺失暂缓；抓取时间和 force 不能绕过边界。邮件发现的 StatusMatch 官方链接继续回填 HOME/FAQ/Terms，不受旧文章截止限制。

单篇多活动拆分及旧文章之间的关联修复暂缓；范围不清不发布。不是看到相同项目名就归并活动期次。历史表、来源与旧简报保留；旧活动 URL 按明确原ID映射到新详情，未发布／无法关联／旧文章仅归档均有明确状态。

## 运维、验证与未完成项

`JOURNEYPLUS_KNOWLEDGE_READ_MODE=legacy` 是默认值；`unified` 同时切换简报、图和 Agent；`rollback` 暂停推荐和用户写入，保留已发布资料浏览。`JOURNEYPLUS_KNOWLEDGE_PUBLISH_ENABLED` 默认 false。不要把预览或测试结果当作正式发布授权；原 product-api 启动流程会迁移配置所指数据库，验证必须明确选择隔离库。

0024 的用户操作日志只保存会籍与独立等待业务操作，不是新增画像或 Agent 记忆。已在独立 PostgreSQL 副本验证备份恢复、迁移往返、切换后新增／修改、幂等重放及冲突拒绝。回滚保留增量知识／目录依赖，不把新任务交给旧 schema；先停止并排空所有进程再建检查点或重放。操作命令见[切换与恢复手册](../openspec/changes/rebuild-membership-knowledge-and-agent/rollout-runbook.md)。

隔离库已完成八项邮件官方活动的安全回填与旧入口核对；Kenya 184 条、Vietnam 175 条映射已读回，17 项费用关联不足仍保留未知。真实开发集及关键重复场景已完成；首次未调参保留集为 8/10，发现问题后的重复测试属于回归，不能改称未见保留集全通过。新旧读取影子对照已完成并分类修正入口和同一目录身份衔接问题。正式数据库尚未迁移／默认消费者尚未切换，发布前当前官网状态检查、稳定观察及旧存储退役未执行，change 未归档。

详细实现约束分别见[数据库](../openspec/changes/rebuild-membership-knowledge-and-agent/database-design.md)、[数据接口](../openspec/changes/rebuild-membership-knowledge-and-agent/data-access-design.md)、[运行时](../openspec/changes/rebuild-membership-knowledge-and-agent/agent-runtime-design.md)、[展示与经验](../openspec/changes/rebuild-membership-knowledge-and-agent/presentation-research-design.md)及[贯通验收](../openspec/changes/rebuild-membership-knowledge-and-agent/end-to-end-design.md)。

来源映射在活动详情内折叠，可筛选项目／等级并分页浏览；条件及脚注保留，浏览零模型。目录只使用经审查的确切项目拼写和官方表头证明的等级别名衔接同一身份，保留历史ID，不猜等级等价。路径搜索按来源身份建立邻接索引，技术边预算用于实际相关映射检查；即使已发布图搜索完成，有活动资料缺口时仍返回部分覆盖。
